# Chastity Events

A Home Assistant custom integration with monthly challenge and LGBTQ+ observance calendars, discovered community/LGBTQ+/sauna event calendars, focused event sensors, a nearest-sauna venue sensor, and Event Hub notification/directions buttons.

Event discovery uses public search/RSS results and optional Ticketmaster data. Listings are best-effort leads, not a verified directory; confirm event dates, venue details, eligibility, and access requirements with the organiser. Sauna venue discovery uses OpenStreetMap and a small maintained UK fallback index.
